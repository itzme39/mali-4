# MALI — vuelve a sentir

Experiencia web interactiva con fotografías, animaciones y música, creada con HTML, CSS y JavaScript.

## Ejecutar localmente

Con Node.js instalado:

```sh
node server.cjs
```

Abre http://localhost:4173 en el navegador.

El punto de entrada es `index.html`. Conserva las carpetas de imágenes, GIF, miniaturas y fuentes junto con los archivos del proyecto.
